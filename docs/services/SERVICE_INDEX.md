## 📝 Documentation Standards

### Each Service Gets 3 Documents:

1. **Backend Service** (`docs/services/<name>-service.md`)
   - Database schema
   - REST API endpoints
   - Java code structure
   - Configuration
   - Testing guide

2. **WebSocket Handler** (`docs/handlers/<Name>Handler.md`)
   - Protocol definition
   - Operation codes
   - Handler implementation
   - Feign integration
   - Testing guide

3. **Frontend Client** (`docs/clients/<Name>Service.md`)
   - TypeScript service class
   - React hooks
   - Component examples
   - Unit & E2E tests
